# Low-Rank Adaptation (LoRA) Implementation

This directory contains implementations and practice files for parameter-efficient fine-tuning using Low-Rank Adaptation (LoRA) in PyTorch.

## Contents
*   **`LoRA_implementation_with_pytorch.ipynb`**: Complete step-by-step implementation of custom LoRA linear layers, inserting them into a neural network, and training/evaluating the fine-tuned model.
*   **`basic.ipynb`**: Introduction and basic concepts of low-rank matrix decomposition applied to model parameters.
*   **`data/MNIST/`**: Local cache of the MNIST handwritten digit dataset used for the LoRA fine-tuning demonstrations.
