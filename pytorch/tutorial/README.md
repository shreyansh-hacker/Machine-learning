# PyTorch Tutorials and Notebooks

Hands-on tutorials for standard neural network architectures and hyperparameter optimization using PyTorch.

## Contents
*   **`ann_fmnist_gpu_optimized_optuna.ipynb`**: Artificial Neural Network on Fashion-MNIST with GPU acceleration and Optuna hyperparameter optimization.
*   **`basic_ofpytorch.ipynb`**: Foundational concepts including PyTorch tensors, operations, and variables.
*   **`cnn.ipynb`**: Building Convolutional Neural Networks (CNNs) for image feature extraction and classification.
*   **`fminst.ipynb`**: Multi-Layer Perceptron (MLP) trained on the Fashion-MNIST dataset.
*   **`mnist_gpu.ipynb`**: Handwritten digit recognition model on MNIST optimized for GPU training.
*   **`pytorch_autograd.ipynb`**: In-depth look at PyTorch's Automatic Differentiation (autograd) engine.
*   **`fmnist_small.csv`**: Subset of the Fashion-MNIST dataset for lightweight local testing.
