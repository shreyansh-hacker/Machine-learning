# PyTorch Workspace

This folder is dedicated to building and optimizing deep learning models using the PyTorch framework.

## Subdirectories
*   **[tutorial](./tutorial)**: Basic and advanced deep learning tutorials utilizing PyTorch for computer vision and standard neural networks.

## Datasets
*   **`MNIST/`**: Local cache of the MNIST dataset used for tutorial training runs.
*   **`fashion-mnist_train.csv` / `mnist_train.csv` / `mnist_test.csv`**: MNIST datasets for standard neural network models.
