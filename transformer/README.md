# Transformer Architecture from Scratch

This directory implements the standard Transformer architecture based on the "Attention Is All You Need" paper.

## Contents
*   **`transformer.ipynb`**: Complete step-by-step implementation including:
    *   Self-Attention & Multi-Head Attention mechanisms.
    *   Positional Encoding.
    *   Encoder & Decoder layers.
    *   Sequence-to-sequence testing.
