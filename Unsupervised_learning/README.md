# Unsupervised Learning

This folder contains Jupyter Notebooks implementing unsupervised learning tasks.

## Notebook Registry & Audit

*   **`k_means.ipynb`**: Performs clustering and centroid updates from scratch.
*   **`Anomaly_detection.ipynb`**: Detects abnormal occurrences by density estimations.
*   **`KNN_classification.ipynb` / `KNN_regression.ipynb`**: Examines nearest-neighbor algorithms for classification and regression tasks.
