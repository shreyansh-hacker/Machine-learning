# Supervised Learning from Scratch

This directory serves as a learning hub for implementing supervised learning algorithms from mathematical first principles using **NumPy** and **Matplotlib**.

## Subdirectories

*   **[Classification](./Classification)**: Classification algorithms practice.
*   **[Regression](./Regression)**: Complete from-scratch regression implementations.
*   **[week2](./week2)**: Structured learning progress workspace.

## File Registry & Audit

*   **`gd_cf.py`**: Vectorized Simple Linear Regression using Gradient Descent and Mean Squared Error cost calculations.
*   **`gd_cf copy.py`**: Loop-based (non-vectorized) Simple Linear Regression to demonstrate the educational comparison with vectorized NumPy operations.
*   **`w_and_b_values_in_given_data.py`**: Closed-form analytical solver (Normal Equation method) using statistical summation formulas to calculate optimal $w$ and $b$ parameters.
*   **`data_augementation.py`**: Demonstrates horizontal flipping, rotation (15°), and shifting on Fashion-MNIST images using PIL, saving the result to `augmented_fashion.png`.
*   **`data_augmentaion1.py`**: Extra utility demonstrating image rotations and shifts.
*   **`test.py`**: Experimental script analyzing model response to PIL-augmented images.
