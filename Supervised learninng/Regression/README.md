# Supervised Regression

This folder groups regression algorithms, ranging from linear to polynomial models, implemented from mathematical concepts.

## Subdirectories
*   **[Linear Regression](./Linear%20Regression)**: Basic single-variable regression.
*   **[Logistic Regression](./Logistic%20Regression)**: Classification modeled via logistic curves.
*   **[Multiple Regression](./Multiple%20Regression)**: Vectorized multi-feature regression.
*   **[Polynomial Regression](./Polynomial%20Regression)**: High-degree curve fitting.
