# Logistic Regression from Scratch

This folder contains code implementing binary classification using custom logistic regression math.

## File Registry & Audit

*   **`linear_logistic_regression_clean.py`**: Implements sigmoid activation and vectorized cross-entropy cost (with epsilon clipping to prevent underflow) on synthetic binary data.
*   **`polynomial_logistic_regression_clean.py`**: Generates non-linear decision regions using custom degree-3 polynomial features, sigmoid activation, and gradient descent.
*   **`plr-root_cube_ft.py`**: Performs multi-feature linear regression with hand-engineered features ($x$, $\sqrt{x}$, $x^3$, and $e^x$) using gradient descent.
*   **`polynomial_logistic_regularization.ipynb`**: Regularization techniques in non-linear classification.
*   **`linear_logistic_regression.py.ipynb`**: Interactive notebook for classification studies.
