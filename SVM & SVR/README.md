# Support Vector Machines (SVM) & Support Vector Regression (SVR)

This folder contains notebooks illustrating the mathematical formulation and usage of Support Vector machines for classification and regression tasks.

## Notebook Registry & Audit

*   **`svm_hinge_loss_based.ipynb`**: Explores the primal formulation of SVMs utilizing hinge loss optimization.
*   **`svm_lagrange_based.ipynb`**: Details the dual formulation of SVM using Lagrange multipliers, allowing the use of kernel tricks (Linear, Polynomial, RBF) for non-linear boundaries.
*   **`svr_Episilon_loss.ipynb`**: Demonstrates Support Vector Regression utilizing the $\epsilon$-insensitive loss function.
*   **`svr_lagrange_based.ipynb`**: Dual SVR formulation highlighting support vectors defining the regression boundary margin.
