# Machine Learning Algorithms Repository

Welcome to the **Machine Learning Algorithms Repository**! This workspace is dedicated to exploring both **from-scratch (mathematical)** and **library-based (Scikit-Learn)** implementations of supervised, unsupervised, and reinforcement learning algorithms.

## Repository Overview
This project contains the following primary directories:

*   **[Implement_algorithms_using_sklearn](./Implement_algorithms_using_sklearn)**: Implementations of classic ML models (regression, classification, clustering, anomaly detection, SVMs) leveraging Scikit-Learn.
*   **[LoRA](./LoRA)**: Implementations of Low-Rank Adaptation fine-tuning on PyTorch models.
*   **[Neural Network](./Neural%20Network)**: Deep dive into Artificial Neural Networks (MLPs) built from scratch (using NumPy) on MNIST/Fashion-MNIST, with discussions on normalization and data augmentation.
*   **[pytorch](./pytorch)**: Deep learning workflows, custom layers, and hyperparameter optimization utilizing the PyTorch framework.
*   **[SVM & SVR](./SVM%20%26%20SVR)**: Jupyter Notebooks containing the mathematical formulations and implementations of Support Vector Machines and Support Vector Regression.
*   **[Supervised learninng](./Supervised%20learninng)**: Custom supervised learning models (classification and regression) written from first principles (gradient descent, cost functions, analytical normal equations).
*   **[transformer](./transformer)**: Implementing attention mechanisms and Transformer encoder/decoder architectures.
*   **[Unsupervised_learning](./Unsupervised_learning)**: Exploration of unsupervised learning paradigms including K-Means, Anomaly Detection, and KNN regression/classification.
*   **[vit](./vit)**: Vision Transformer (ViT) architecture modeling and fine-tuning.
*   **[reinforcement](./reinforcement)**: Introductory workspace for Reinforcement Learning concepts.

## Core Files
*   **`pca.py`**: A complete, from-scratch implementation of **Principal Component Analysis (PCA)** using NumPy's eigenvalue decomposition.
*   **`optimizers_comparison.ipynb`**: Comprehensive comparison of various optimization algorithms (SGD, Adam, RMSprop, etc.) on deep learning tasks.
